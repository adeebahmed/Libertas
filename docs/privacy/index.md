# Why Private

One rule: your financial data stays on your machine.

## No account linking required

Libertas is designed around file imports and manual entry. You do not need to hand over institution credentials to get value.

## No cloud dependency for core value

The core app runs locally with SQLite. Your day-to-day workflow does not depend on a cloud account to be usable.

## No hidden analytics profile

Libertas is open source. You can inspect the code and verify behavior directly.

## Optional AI, explicit opt-in

AI chat is optional and only runs when you provide your own API key. You decide when and how to use it.

## How to verify yourself

- Inspect code paths in the repository.
- Check browser network activity while using the app.
- Review your local `data/libertas.db` and backup files.
